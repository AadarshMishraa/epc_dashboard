# Learnings and traps

One bullet each, newest last. Format: `- YYYY-MM-DD [area] what is true — why it matters (evidence)`.
- 2026-11-04 [toolchain] TypeScript 7.0 (npm `latest`) is the native port with only `unstable/*` APIs; typescript-eslint 8.x needs `typescript <6.1`. Pin 6.0.x until both move (npm view, 2026-11-04).
- 2026-11-04 [env] The cloud container ships Node 22; the repo requires Node 24 and install refuses 22. Use a Node 24 binary (download from nodejs.org, verify SHASUMS256) and put it first on PATH.
- 2026-11-04 [workspace] Tests and typecheck resolve `@gx/*` to source through the `@gx/source` export condition (vitest `resolve.conditions`, tsconfig `customConditions`); runtime and `tsconfig.build.json` resolve to `dist/`. A generic `source` condition name would also match third-party packages, so it is namespaced.
- 2026-11-04 [compliance] privacycheck flags prose that names a forbidden field (tools/plangen/epc_gen.py:582 "Do not store Aadhaar numbers"). It is a false positive, but it will fail the privacycheck CI stage (K0-T10) until the checker or the text changes.
- 2026-11-04 [map] codemap.py does not resolve `@gx/*` workspace imports, so MAP.md under-reports package dependencies; `pnpm check:imports` is the authority for the package graph.
- 2026-11-04 [env] The cloud session's network policy blocks government and review sites (pmsuryaghar.gov.in, g2.com, capterra.in), so web research returns search summaries only. Treat it as leads and verify by hand or allow the hosts.
- 2026-11-04 [env] No Docker daemon in the cloud container, so `supabase start` cannot run here; database integration tests need local Postgres or CI.
- 2026-11-04 [migrations] A keyword deny-list misses security changes (DISABLE RLS, ALTER POLICY, DO blocks, END). Judge statements by an allow-list of heads, and gate security statements separately from destructive ones.
- 2026-11-04 [env] The sandbox refuses to run downloaded database binaries; use the system Postgres 16 locally and pin 17 in CI.
- 2026-11-04 [postgres] COMMIT on a failed transaction performs a rollback, so 'replace ROLLBACK with COMMIT' is an equivalent mutation; prove atomicity with fault injection instead.
- 2026-11-05 [env] The Mac has no Node 24, only Node 26 from Homebrew. A checksum-verified official Node 24 tarball in the session scratchpad, plus `corepack enable --install-directory <that bin>`, gives pnpm 10.34.9. node_modules was not installed before this session.
- 2026-11-05 [tooling] macOS sed has no `\b`. A rename with `\bName<` silently matched nothing, and `pnpm api:update` still reported 0 problems (TD-5). Run `pnpm typecheck` after any scripted rename.
- 2026-11-05 [tooling] zsh does not word-split unquoted $var, so a helper that passes "--project core" as one variable gives vitest one bad argument and prints nothing. Pass flags as separate quoted arguments.
- 2026-11-05 [env] The Mac shell has a SUPABASE_ACCESS_TOKEN set that Supabase rejects as invalid, and the global CLI is 2.109.1 while config.toml came from 2.122.0. Link this repo with a project-specific token set per command, never `supabase login`, so the other project's CLI state stays untouched. `curl` did not resolve in the Bash tool late in the session; Node `fetch` works.
- 2026-11-12 [tooling] A unicode escape (backslash-u plus four hex digits) written into a source file through the editor tool can arrive as the raw character and break a regex literal. Build such characters with `String.fromCodePoint(...)` in tests, and check the written file for non-ASCII characters.
- 2026-11-12 [tooling] `privacycheck.py` flags the national-id word and `card_number` anywhere in source, and any personal-data word on the same line as `logger.x(`. Put deny-list entries on a line with `privacycheck:ignore`, and build log fields on their own lines.
- 2026-11-12 [typescript] A callback typed `=> void` accepts an async function, so a rejecting promise goes unhandled and Node 24 exits. Where a host supplies a callback, type it `=> unknown` and handle a returned thenable.
- 2026-11-13 [plangen] `epc_gen.py` also writes the pack's `domain-notes.md` and, while it shows no progress, `STATUS.md`. A hand edit to either is lost on the next run: change the generator. Run it twice and check that `git diff --stat packs` does not change.
- 2026-11-13 [plangen] The decision ids in the pack STATUS (D-nn) come from the position in the `DECISIONS` list, so a new decision inserted before an old one renumbers it. Append new decisions at the end, and new features after the last feature, so no id moves.
- 2026-11-13 [env] A resumed session gets a new scratchpad folder, so the Node 24 tarball from an earlier session may be gone and `pnpm` is not found. Re-download and verify it (LEARNINGS 2026-11-05) before `pnpm verify`.
- 2026-11-15 [postgres] A WHERE clause that reads a column makes UPDATE and DELETE meet the SELECT policy too, so a filtered probe (`WHERE tenant_id = <other>`) returns 0 even when the UPDATE or DELETE policy is `USING (true)`. Only a bare `DELETE FROM t` or `UPDATE t SET ...` tests those policies. The same rule means an UPDATE with a WHERE cannot move a row to a tenant whose rows you cannot read, so a loose `WITH CHECK` shows only on a bare update. Tenant-isolation tests must run both forms (found by gx-staff-reviewer on K0-T06).
- 2026-11-15 [postgres] A bare `DELETE FROM parent` fails on the foreign key as soon as a child row exists, and says nothing about isolation. The matrix probes referenced tables first. A rerun on the same database hits the same wall, so tenant-matrix runs need a fresh database.
- 2026-11-15 [postgres] RLS is not inherited by partition children: the parent returned 0 rows of another tenant while the child read directly returned them. Policy `WITH CHECK` runs before the constraint checks on INSERT, so a unique clash cannot stand in for a policy refusal in a test.
- 2026-11-15 [env] A Postgres `unix_socket_directories` path under the macOS scratchpad is too long (103-byte limit). Start a throwaway server with `-c unix_socket_directories= -c listen_addresses=127.0.0.1 -p 54329`. The migrate db test expects the connecting role to be named `gx_test` (superuser).
- 2026-11-15 [tooling] A mutation pass (script that swaps one rule, runs both vitest suites, restores from an in-memory copy) found 6 of 39 survivors that the angle matrix had marked covered: a check that two tests could both trip, a `seed` violation that a crash also produces, and an error-state filter no test exercised. Assert on the violation's detail text, not only its check name.
